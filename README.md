# TexTech Construction Website

## Project Status

This is a sanitized Vite + React production website for TexTech Construction.

The project has been cleaned for STG / SDL standards:

- Local asset structure under `/public/images`
- Standard React Router routing
- Vite production build workflow
- Static marketing-site architecture

---

## Tech Stack

- React
- Vite
- React Router
- Tailwind CSS
- shadcn-style UI components
- Lucide React icons
- Framer Motion
